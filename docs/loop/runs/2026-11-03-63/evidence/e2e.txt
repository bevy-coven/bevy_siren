## The miss is a tie, and it is the honest kind

`white noise hiss` put `rain.wav` (0.429) ahead of `noise.wav` (0.423) — a **0.006** gap, where the same query's
gap to everything else is 0.39. Both clips are generated from white noise; `rain.wav` is amplitude-modulated white
noise. So the model is calling the two nearly the same thing, correctly, and the tie-break decided it.

**`rain falling` makes the same call from the other side**: `noise.wav` (0.126) over `rain.wav` (0.115). Given that
`rain.wav` *is* unmodulated noise plus an envelope, preferring the unmodulated one for the literal words is defensible.

## What this proves

| | |

| a description reaches a library and ranks something | **yes** |
| the right clip is first when the categories differ | **yes**, 3 of 3 unambiguous |
| near-identical clips tie | **yes**, and the scores say so — 0.429 vs 0.423 |
| the score is informative enough to see the tie | **yes**, which a bare "best match" would have hidden |

The last row is the argument for `Match::score` and for `Answer::describe`: a 1-of-1 answer and a 1-of-2-tied answer
look identical without the numbers.
