The crate does not ship the model (CLAP, laion/clap-htsat-fused, MIT). Make the files once, from the weights in
your Hugging Face cache or by download:

    python3 tools/export_clap_onnx.py <dir>

It writes clap-text.onnx, clap-audio.onnx, tokenizer.json and clap-export.txt. This build runs the model on the CPU
(CPU, fp32 — no CUDA device in this build; an index built on a GPU may rank differently here), so a machine with no GPU is fine; a machine with no model is not.
