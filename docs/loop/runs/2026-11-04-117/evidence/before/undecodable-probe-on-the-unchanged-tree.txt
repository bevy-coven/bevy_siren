What this shows:
 - six kinds of undecodable file, six `Played`, six panics at bevy_audio-0.20.1/src/audio_source.rs:101:14, in the first update after the play. `refused` is empty every time: the crate's own rule
   (every play answers exactly one of Played/Refused, and nothing plays on a refusal) is false for these files on the default build.
 - the decoder's words are identical for all six rows ("The format of the data has not been recognized."), so a refusal that says only that cannot tell an author that the file is a Git LFS pointer.
 - what the decoder reads is a property of the BUILD: mulaw.wav is Err with hound (default) and Ok with symphonia's WAV (the mixer feature); mp3 and flac are Err in the default build and Ok with the mixer
   feature. A check that asks the decoder inherits this; a table of formats would not.
 - the cost of asking: a Vorbis decoder is 0.64 - 0.75 ms to construct whatever the length (setup-header codebooks), hound's WAV 0.1 - 0.2 µs, symphonia's WAV / MP3 / FLAC 10 - 180 µs
   (growing with the file's size). Bevy pays the same on EVERY play; asking once per asset adds one construction per distinct sound.
